Шаг 3: «Линии Ветра» (Анимированные штрихи)

Это самый крутой эффект для темы «Море и Ветер». Мы создадим компонент, который пускает по экрану редкие, тонкие белые линии.

Создай файл WindLines.tsx:

TypeScript
import React, { useEffect, useRef } from 'react';
import gsap from 'gsap';

export default function WindLines() {
  const containerRef = useRef(null);

  useEffect(() => {
    const lines = gsap.utils.toArray('.wind-line');
    
    lines.forEach((line: any) => {
      gsap.to(line, {
        x: '100vw',
        duration: gsap.utils.random(10, 20),
        repeat: -1,
        ease: "none",
        delay: gsap.utils.random(0, 10),
        onRepeat: () => {
          gsap.set(line, { y: gsap.utils.random(0, 100) + 'vh', x: '-10vw' });
        }
      });
    });
  }, []);

  return (
    <div ref={containerRef} className="fixed inset-0 pointer-events-none z-[5] overflow-hidden opacity-20">
      {[...Array(5)].map((_, i) => (
        <div 
          key={i} 
          className="wind-line absolute h-px w-20 bg-gradient-to-r from-transparent via-[#D4AF37] to-transparent"
          style={{ top: `${Math.random() * 100}vh`, left: '-10vw' }}
        />
      ))}
    </div>
  );
}
Добавь <WindLines /> в App.tsx прямо под курсором.
