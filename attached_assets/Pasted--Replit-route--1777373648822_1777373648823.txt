Типичная выходка ИИ. Посмотри на логи Replit на твоем скриншоте слева, агент гордо заявляет: «route "/" now points to <Story />...».

Вместо того чтобы добавить новый блок под первым экраном, он просто затер корневой файл и сделал Story единственным элементом на всем сайте.

При этом сама типографика (гигантская прозрачная 01, правильные шрифты и отступы) встала идеально. Выглядит дорого. Но фото пластиковой банки с лосьоном от рандомайзера Unsplash вместо сицилийского завтрака — это, конечно, провал. Заменишь потом на свои крутые исходники.

Давай быстро починим сборку руками, чтобы не зависеть от самодеятельности агента.

Открой свой корневой файл (скорее всего это App.tsx или App.jsx) и полностью замени его содержимое на этот код. Мы заново собираем "бутерброд" из наших компонентов и возвращаем настройку плавного скролла.

TypeScript
import React, { useEffect } from 'react';
import Hero from './Hero'; // Твой первый экран
import Story from './Story'; // Твой новый журнальный блок
import Lenis from '@studio-freight/lenis';
import gsap from 'gsap';
import { ScrollTrigger } from 'gsap/ScrollTrigger';

// Регистрируем плагин
gsap.registerPlugin(ScrollTrigger);

export default function App() {
  useEffect(() => {
    // Настраиваем дорогой "масляный" скролл
    const lenis = new Lenis({
      duration: 1.2,
      easing: (t) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
      smooth: true,
    });

    lenis.on('scroll', ScrollTrigger.update);

    gsap.ticker.add((time) => {
      lenis.raf(time * 1000);
    });
    gsap.ticker.lagSmoothing(0);

    return () => {
      gsap.ticker.remove(lenis.raf);
      lenis.destroy();
    };
  }, []);

  return (
    // Собираем страницу: сначала Hero, затем сразу Story
    <main className="bg-white min-h-screen">
      <Hero />
      <Story />
    </main>
  );
}
Техническая деталь: убедись, что файлы Hero.tsx и Story.tsx лежат в той же папке.

Обнови превью. Ты должен увидеть ваш темный кинематографичный первый экран с виджетом бронирования, а при скролле вниз страница должна плавно перетечь в белую журнальную секцию 72 Ore Perfette.
