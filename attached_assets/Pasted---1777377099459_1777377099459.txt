2. GSAP Логика (Замени старый useEffect)

Вот новые настройки покачивания. Я увеличил угол до 8 градусов и сделал движение более плавным, но заметным.

JavaScript
// Внутри useEffect в Hero.tsx
if (sailboatRef.current) {
  gsap.to(sailboatRef.current, {
    rotation: 8, // Было 3, стало 8 — теперь покачивание хорошо видно
    duration: 2.5, // Медленный, тяжелый ритм дорогой яхты
    ease: "power1.inOut",
    repeat: -1, // Бесконечно
    yoyo: true, // Туда-обратно
    transformOrigin: "center bottom" // Качается от основания мачты
  });
}
